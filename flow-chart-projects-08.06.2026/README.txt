# Algorithmic Foundations & Flowchart Projects

This repository contains a collection of fully functional applications and flowchart projects designed to demonstrate core programming logic, data flow structures, and fundamental algorithmic principles. 

Each project focuses on a unique problem-solving scenario, utilizing conditional logic, loops, and mathematical computations to achieve optimized workflows.

## 🚀 Projects Overview

| # | Project Name | Description | Key Algorithmic Concepts |
|---|---|---|---|
| 1 | **2-sayidan-buyuk-olani-bulma** | Finds the maximum value between two user-inputted numbers. | Conditional Logic (`If-Else`), Comparison Operators |
| 2 | **5e-kadar-olan-sayilardan-isim-yazdirma** | Iterates up to 5, printing a predefined string/name dynamically. | Definite Loops (`For`/`While`), Counter Variables |
| 3 | **100-luk-sistemi-5-lik-sisteme-cevirme** | Converts a 100-point grading scale into a standard 5-point system. | Mapping Algorithms, Multi-way Conditionals |
| 4 | **diktörtgen-uzun-kanar-kısa-kenar-bulma** | Determines and differentiates between the short and long edges of a rectangle based on dimensions. | Geometric Logic, Validation, Variables |
| 5 | **girilen-5-sayinin-ortalamasini-bulma** | Takes 5 distinct numeric inputs from the user and calculates their mathematical average. | Accumulator Pattern, Arithmetic Operators, Data Aggregation |
| 6 | **girilen-sayiya-kadar-yazdirma** | Dynamically prints sequences starting from 1 up to N (user's target input). | Indefinite/Definite Looping, Execution Flow Control |
| 7 | **maddenin-halleri** | Classifies and evaluates the states of matter based on physical parameters like temperature. | State Logic, Classification, Multi-conditional Decision Trees |
