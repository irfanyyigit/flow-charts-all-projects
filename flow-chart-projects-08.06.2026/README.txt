Algorithmic Foundations & Flowchart Projects
Description

This repository contains a collection of flowchart-based projects designed to demonstrate fundamental programming concepts, algorithmic thinking, and problem-solving techniques.

Each project focuses on a specific scenario and showcases core programming principles such as conditional statements, loops, mathematical operations, and decision-making structures. The primary objective is to help learners develop a strong foundation in algorithm design and logical reasoning.

Technologies

The following technologies and tools were used throughout these projects:

Flow Turkuaz
Flowchart Programming (.fpp)
Algorithm Design Fundamentals
Flowchart Development
Projects
1. 2-sayidan-buyuk-olani-bulma

Determines the larger value between two user-provided numbers.

Key Concepts:

Comparison Operators
Conditional Statements (If-Else)
Decision Making
2. 5e-kadar-olan-sayilardan-isim-yazdirma

Prints a predefined name or text repeatedly using a loop until a specified limit is reached.

Key Concepts:

Loops
Counters
Repetitive Operations
3. 100-luk-sistemi-5-lik-sisteme-cevirme

Converts grades from a 100-point grading scale to a standard 5-point grading system.

Key Concepts:

Data Transformation
Multi-Condition Logic
Classification Algorithms
4. diktörtgen-uzun-kanar-kısa-kenar-bulma

Identifies and distinguishes the longer and shorter sides of a rectangle based on user input.

Key Concepts:

Geometric Calculations
Comparison Logic
Input Validation
5. girilen-5-sayinin-ortalamasini-bulma

Calculates the arithmetic mean of five numbers entered by the user.

Key Concepts:

Arithmetic Operations
Data Aggregation
Accumulator Pattern
6. girilen-sayiya-kadar-yazdirma

Prints numbers sequentially from 1 up to a user-defined limit.

Key Concepts:

Loop Structures
Execution Flow Control
Counter Variables
7. maddenin-halleri

Classifies the physical state of matter based on predefined conditions.

Key Concepts:

Decision Trees
Classification Logic
Multi-Conditional Structures
Installation

To run these projects, you will need Flow Turkuaz or any compatible software that supports .fpp files.

Steps
Install Flow Turkuaz on your computer.
Clone or download this repository.
git clone https://github.com/your-username/repository-name.git
Open the desired .fpp project file using Flow Turkuaz.
Run the project and review the flowchart execution.
Usage

Each project is designed to operate independently.

Open the desired project file.
Review the flowchart structure and logic.
Provide the required user inputs.
Execute the flowchart and analyze the output.

These projects are intended for students, beginners, and anyone interested in learning the fundamentals of algorithms, flowchart design, and logical problem-solving.
